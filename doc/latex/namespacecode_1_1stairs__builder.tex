Utility to build a stair automata with an arbitrary amount of loops. 

A stair automaton with k loops is an automaton that has k negative loops composed of four transitions\+: -\/i, +i, +k, -\/k-\/1+i. This type of automaton results in a stair-\/shaped energy function on the diagonal Each loop adds 3 new states to the automaton. These kind of automata are useful for benchmarking our algos since they can be as large as we want
