\doxysubsection{Detailed Description}
Utility functions for solving energy problems in weighted Büchi automata. 

This file contains our main contributions, notably~\newline
 The main algorithm, algorithm 1 in the paper~\newline
 The helper algorithms for energy computations,~\newline
 subsumed in algorithm 2 in the paper~\newline
